# Milestone M4.2 — production shared-bottom training

M4.2 trains the frozen shared-bottom MLP on the 722,481 authorized normal-policy impressions from April 12–29, 2022. Production seeds 0, 1, and 2 each completed the approved fixed budget of 7,060 optimizer updates with `drop_last=False`, exactly five complete data traversals and 3,612,405 examples.

## Frozen training contract

- Architecture: 649,411-parameter shared-bottom MLP with `[128, 64]` hidden dimensions and dropout 0.1.
- Inputs: frozen FS3 numerical/categorical fields, separate user/video ID embeddings, and masked-mean last-20 video history.
- Heads: long view and like on all rows; valid play only where `click_semantics == "valid_play"` (tab 1).
- Loss: per-task mask-normalized binary cross-entropy with equal weights `[1, 1, 1]`.
- Optimization: AdamW, learning rate 0.001, weight decay 1e-5, constant schedule, batch size 512.
- Budget: 7,060 updates and 3,612,405 examples per seed. This same update budget is frozen for MMoE and later RQ3 neural arms even when their epoch counts differ.
- Model selection: no early stopping, validation scoring, or hyperparameter tuning.

The training runner validates every fixed value, input date range, row count, manifest hash, preprocessing hash, and `drop_last=False` before training. It fails unless final update and example counters match the approved values exactly.

## Artifacts and reproducibility

Run an individual approved seed with:

```bash
source .venv/bin/activate
python scripts/train_shared_bottom.py --seed 0
```

Replace `0` with `1` or `2`. Each bundle is stored at `~/recom/models/neural/shared_bottom/v1/seed_<seed>/` and contains:

- `checkpoint.pt`: model and optimizer state;
- `checkpoint_manifest.json`: checksum-bound configuration, protocol, population, task-mask and budget metadata;
- `training_log.jsonl`: every optimizer update with overall/per-task loss, cumulative examples, elapsed time and learning rate;
- `run_report.json`: runtime, memory, loss summaries, hashes, sizes and reload results.

The runner compares probabilities for the first 1,024 canonically aligned impressions before and after reload. All three seeds are bit-exact (`torch.equal`) with maximum absolute difference 0.0. Checkpoint loading rejects incomplete, stale, incompatible or checksum-modified bundles.

No randomized-validation or May 3–8 outcomes were accessed. MMoE and ablation models were not trained.
