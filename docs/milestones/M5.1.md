# M5.1 — RQ3 exposure-aware training-data preparation

M5.1 prepares, but does not train, three FS1-deep LightGBM strategies for RQ3. The architecture is the M4.5-selected normal-validation configuration and remains fixed at 300 boosting rounds with the M3.2b deep-tree hyperparameters.

## Training populations

| Strategy | Source and dates | Rows | Source indicator in model |
|---|---|---:|---|
| Marginal-exposure reweighting | Normal, Apr 12–29 | 722,481 | No |
| Normal + random fusion | Normal Apr 12–29 + random Apr 22–29 | 1,060,414 | Yes |
| Random only | Random, Apr 22–29 | 337,933 | No |

All inputs reuse frozen FS1 fields. Randomized interactions never enter feature history. The joint adapter alone includes `context__is_rand`; it is fitted on the combined authorized population, and its value must be set to 1 for later randomized-exposure evaluation. The random-only adapter fits categorical vocabularies on random-training rows only. The weighting arm uses the exact frozen baseline normal-training adapter.

## Approved weighting rule

For video `i`, let `n_i` be its impression count among the 722,481 normal-training impressions. The prospective M5.1 decision is:

1. Compute raw row weight `1 / (n_i + 1)`.
2. Calculate the observation-weighted 99th percentile across normal-training rows using the linear quantile definition.
3. Upper-clip raw weights at that value.
4. Divide by the arithmetic mean of clipped training weights.
5. For an unseen video, use the frozen clipped maximum before applying the same normalization factor.

This is a marginal-exposure SNIPS-style training heuristic, not causal IPS: marginal item frequency is not a user/context-conditional logging propensity.

## Prepared training interface

`kuairand_pure.rq3.load_prepared_rq3_task` verifies artifact checksums, artifact/build manifests, exact impression-ID alignment, the strategy-specific adapter, source-indicator policy, and aligned positive finite sample weights before returning the long-view training matrix. It fails rather than silently realigning inputs.

All strategies inherit learning rate 0.05, 127 leaves, maximum depth 10, minimum 100 observations per leaf, L2 regularization 1.0, seed 202211, deterministic single-thread execution, and 300 rounds. Matched rounds do not match sample count, CPU work, or training distribution.
