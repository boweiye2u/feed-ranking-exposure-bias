# Milestone M3.2b — full LightGBM training

M3.2b trains the frozen normal-policy LightGBM matrix on April 12–29, 2022 only. It does not access validation, randomized-training, or final-test outcomes and performs no model selection.

## Training contract

The matrix is FS1/FS2/FS3 × shallow/deep × four distinct binary tasks. Long view and like use all 722,481 authorized normal-training impressions. Valid play uses the 535,569 tab-1 rows; literal click uses the 78,575 tab-0 rows. A pooled click target remains forbidden. Every task had both outcome classes.

All models use learning rate 0.05, 300 rounds, seed 202211, one deterministic thread, minimum 100 observations per leaf, and L2 regularization 1.0. Shallow uses 31 leaves and depth 6; deep uses 127 leaves and depth 10. No early stopping or outcome-driven adjustment was used.

Before the matrix, the exact FS3 shallow long-view configuration passed the production resource gate: 722,481 rows and 83 features trained in 46.02 seconds with 1,652.8 MiB peak process RSS. Input encoding took 10.69 seconds and categorical-vocabulary fitting took 8.41 seconds. The saved and reloaded model produced bit-identical probabilities in [0, 1], and this accepted bundle was reused as the corresponding matrix cell.

## Artifact contract

Models are outside Git under `~/recom/models/lightgbm/v1/<feature-set>/<complexity>/<task>/`. Each directory contains:

- `model.txt`: LightGBM model;
- `adapter.json`: exact feature order/types and training-only categorical vocabularies;
- `model_manifest.json`: build/config versions, task population, dates, row counts, feature-manifest checksum, hyperparameters, seed, software versions, protocol identifiers, and model/adapter checksums;
- `training_record.json`: resource, size, warning, round-count, alignment, probability-range, and reload diagnostics.

Loading rejects missing files, stale build/config versions, checksum changes, incompatible feature manifests, and mismatched feature-set/task/complexity expectations. Training requires exact row-level feature/label impression-ID equality and never silently realigns inputs.

## Reproduction

```bash
source .venv/bin/activate
python scripts/train_lightgbm_matrix.py benchmark
python scripts/train_lightgbm_matrix.py full
pytest -q
```

The benchmark must pass its fixed 900-second and 12,288-MiB thresholds before `full` will run. Running `full` uses only `normal_train` artifacts from each frozen M2 feature set.

Detailed measured results are in `reports/m3_2b_lightgbm_training.md`; the machine-readable benchmark and matrix reports are under `~/recom/models/lightgbm/v1/`.
