# Milestone M4.3 — production MMoE training

M4.3 trains the frozen full-input MMoE on the same 722,481 April 12–29 normal-policy impressions used by M4.2. Seeds 0, 1, and 2 each completed 7,060 AdamW updates and exactly 3,612,405 examples with batch size 512 and `drop_last=False`.

## Frozen architecture and training contract

The model receives the complete 286-dimensional neural representation: frozen FS3 inputs, separate user/video embeddings, and the masked mean of the aligned last-20 normal-policy video history. It contains four parallel 64-unit experts, one four-way softmax gate for each of the long-view, like, and tab-1 valid-play tasks, and one 32-unit tower per task. Dropout remains 0.1. The model has 687,479 parameters.

The task masks, equal-weight mask-normalized binary cross-entropy, training-only categorical vocabularies, AdamW learning rate 0.001, weight decay 1e-5, constant schedule, and seeds match M4.2 exactly. No class weighting, auxiliary objective, early stopping, or validation decision is present.

Every optimizer update checks logits, loss, and all available gradients for finite values. After the final update the runner requires finite, nonzero gradients in the expert, gate, and tower module families. A full-data diagnostic pass verifies every gate weight is nonnegative and each row sums to one within tolerance. It accumulates only mean/standard deviation, argmax-expert share, entropy, and global extrema; it does not retain per-impression routing tensors.

## Reproduction and artifacts

```bash
source .venv/bin/activate
python scripts/train_mmoe.py --seed 0
```

Replace `0` with `1` or `2`. Bundles are stored at `~/recom/models/neural/mmoe/v1/seed_<seed>/` and contain the checkpoint, checksum-bound manifest, complete per-update JSONL log, and seed-level report. The manifest records architecture, training dates and rows, task definitions, update/example budget, preprocessing and feature-manifest identities, software versions, losses, routing diagnostics, and final gradient norms.

Prediction probabilities for the first 1,024 canonically aligned training impressions are compared before and after checkpoint reload. All three seeds reload bit-exactly with maximum absolute difference 0.0.

No ablation, shared-bottom retraining, validation evaluation, randomized-validation access, or final-test outcome access occurred.
