# M7.1 — final results freeze

M7.1 verifies the complete M6 artifact chain and produces the public-portfolio research package without rerunning experiments. The consolidated report is `reports/final_research_report.md`; compact provenance tables are under `reports/tables/`; six figures are under `reports/figures/` in SVG and PNG.

Rebuild only the presentation assets with:

```bash
MPLCONFIGDIR=/tmp/kuairand-mpl PYTHONPATH=src .venv/bin/python scripts/build_results_package.py
```

The generator refuses to run if the frozen M6.1, M6.2, or M6.3 result hashes, prediction checksums, candidate population, contender population, RQ3 arms, or six comparisons differ. It does not train, score, select, bootstrap, or overwrite large experiment artifacts.

Raw data, processed features, model bundles, and prediction tables remain outside Git under `~/recom/`.
