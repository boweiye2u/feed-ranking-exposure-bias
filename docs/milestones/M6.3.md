# M6.3 — final cross-fitted model-selection regret

M6.3 applies the frozen RQ2 estimator to T-random long-view outcomes and the 12 unchanged RQ1/RQ2 seed-0 candidates. FS1-deep remains the fixed normal-validation workflow pick. RQ3 alternatives are excluded.

The all-candidate and frozen three-contender populations each perform independent reference selection on 50 deterministic disjoint user A/B splits, evaluated in both directions. The random-pick benchmark is the arithmetic mean of candidate AUCs, never an average of prediction probabilities. Uncertainty uses 2,000 paired unique-user multinomial bootstraps and recomputes selection for all 100 directional halves in each replicate.

Run with `PYTHONPATH=src .venv/bin/python scripts/evaluate_rq2_regret.py`. Outputs are stored under `~/recom/evaluation/final/v1/`.
