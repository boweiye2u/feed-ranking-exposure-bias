# M6.2 — final held-out RQ1 and RQ3 evaluation

M6.2 opens May 3–8 normal and randomized outcomes only after validating the complete M6.1 freeze. It evaluates unchanged predictions, executes the six frozen paired comparisons, and does not run RQ2 cross-fitted regret.

The implementation is `kuairand_pure.final_results`; run it with `PYTHONPATH=src .venv/bin/python scripts/evaluate_final_rq1_rq3.py`. Large results are written beneath `~/recom/evaluation/final/v1/`.

Metrics retain the Week-0 definitions: uncapped pair-weighted within-user AUC is primary, with equal-user and 952-capped AUC, pooled AUC, LogLoss, and NDCG@5 secondary. Neural seed 0 is primary and seeds 1–2 are robustness analyses. The six comparisons use 10,000 paired unique-user multinomial bootstraps, percentile intervals, the frozen tail-share approximate p-value, and step-down Holm adjustment.
