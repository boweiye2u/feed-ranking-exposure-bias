# M5.2 — RQ3 exposure-aware LightGBM training

M5.2 trains exactly three alternative long-view predictors using the normal-validation-selected FS1-deep LightGBM architecture. The original normal-only baseline remains untouched.

## Fixed controls

Every arm uses learning rate 0.05, 300 boosting rounds, 127 leaves, maximum depth 10, minimum leaf size 100, L2 regularization 1.0, no bagging, full feature fraction, deterministic single-thread execution, and seed 202211. There is no early stopping, validation-based tuning, architecture search, or learning-rate schedule change.

The arms are:

- `marginal_reweighting`: 722,481 normal-training rows with the approved M5.1 marginal item-frequency weights and exact frozen baseline adapter.
- `joint`: 1,060,414 normal-plus-random training rows with uniform weights and the joint-fitted adapter containing `context__is_rand`.
- `random_only`: 337,933 randomized-training rows with uniform weights and a random-training-fitted adapter.

Matching 300 rounds does not equalize sample size, training distribution, examples processed by trees, or total computation.

## Integrity controls

The runner loads M5.1 inputs through their fail-closed manifests and verifies feature/label/weight alignment, checksums, source-indicator policy, exact population counts, and both target classes. The frozen normal-only baseline is hashed before and after every fit. Each output bundle copies the audited M5.1 adapter byte-for-byte, records full effective parameters and provenance, and must reproduce predictions exactly after reloading.

Training-set prediction ranges are finite-value diagnostics only. They are not used for selection and are not estimates of validation or test ranking performance.

## Reproduction

Run each arm in a separate process to retain per-model peak-memory measurements:

```bash
python scripts/train_rq3_lightgbm.py --arm marginal_reweighting
python scripts/train_rq3_lightgbm.py --arm joint
python scripts/train_rq3_lightgbm.py --arm random_only
python scripts/summarize_rq3_lightgbm.py
pytest -q
```

Bundles are stored under `~/recom/models/lightgbm/rq3/v1/`. The workflow does not evaluate normal validation, randomized validation, or final-test data.
