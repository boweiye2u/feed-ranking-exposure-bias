# M6.1 — held-out features and frozen predictions

M6.1 constructs feature-only FS1, FS2, FS3, and last-20 sequence artifacts for T-normal and T-random (May 3–8, 2022), then scores every frozen candidate without opening target-label tables or calculating metrics.

Aggregate history is normal-policy only and strictly prior calendar day. The rolling-history exception reads normal-policy outcomes from May 3–7 solely so a later target day may use an earlier day's normal interaction history. May 8 outcomes, all randomized outcomes, and all outcomes used as prediction targets remain unopened. Sequence histories contain only structural normal-policy fields and require timestamps strictly earlier than the target.

Predictions contain only `impression_id` and `score`. Long-view and like cover every impression; valid-play covers only `context__tab == 1`; literal-click LightGBM predictions cover only `context__tab == 0`. Training-fitted LightGBM and neural adapters are reused without fitting. Neural seed 0 is primary and seeds 1–2 are retained for robustness. The RQ3 normal-only baseline references the identical FS1-deep long-view prediction by checksum.

Large feature artifacts are under `~/recom/processed/final/v1/`; predictions and the machine-readable M6.1 manifest are under `~/recom/predictions/final/v1/`.

Run with:

```bash
PYTHONPATH=src .venv/bin/python scripts/build_final_predictions.py
```
